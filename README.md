# DUAN LAB — Portfolio

Syndrea Kuo 的個人作品集網站，純 HTML / CSS 打造，無框架、無建置流程。

- 深綠色底 + 白色呼吸燈發光背景（固定定位偽元素動畫）
- 頂部導覽列固定顯示，點擊可平滑捲動到對應區塊
- Hero 主標題 `WELCOME TO MY SPACE`，滑鼠移到 `SPACE` 上會展開技能清單
- About / Experience / Contact 分區捲動呈現

## 資料夾結構

```
portfolio/
├── index.html
├── css/style.css
└── assets/
```

## 本機預覽

直接用瀏覽器打開 `index.html`，或起一個本機伺服器：

```bash
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000
```
